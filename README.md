# Tema: Sistema para Controle Financeiro

Sistema para gestão de finanças pessoais, permitindo o registro e categorização de receitas e despesas.
O projeto tem como objetivo desenvolver um sistema web de controle financeiro pessoal, permitindo que usuários gerenciem suas receitas e despesas de forma simples, prática e organizada. A aplicação busca auxiliar no acompanhamento financeiro diário por meio de ferramentas visuais e funcionalidades intuitivas. O sistema contará com autenticação de usuários, garantindo que cada pessoa tenha acesso apenas às suas próprias informações financeiras. Entre as principais funcionalidades estão o cadastro e gerenciamento de transações financeiras, categorização de despesas e receitas, visualização de saldo total e exibição de estatísticas em dashboard com gráficos simples. Além disso, o sistema permitirá a organização das informações financeiras em uma interface acessível e objetiva. Futuramente, pretende-se implementar uma funcionalidade de metas financeiras (“cofres”), possibilitando ao usuário definir objetivos de economia e acompanhar seu progresso ao longo do tempo.
